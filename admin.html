Connexion

Colle ton jeton d'accès GitHub ci-dessous. Il reste uniquement sur cet appareil et sert juste à publier les événements.

Comment créer ce jeton (une seule fois) ?
  1. Sur GitHub.com, connecte-toi, puis va dans Settings (ta photo de profil, en haut à droite).
  2. Tout en bas du menu de gauche → Developer settings.
  3. Personal access tokens → Fine-grained tokens → Generate new token.
  4. Donne-lui un nom (ex : « Admin CDC »).
  5. Repository access → Only select repositories → choisis siteweb-CDC.
  6. Permissions → Repository permissions → Contents → Read and write.
  7. Generate token, copie-le (il commence par github_pat_) et colle-le ci-dessous. Ne le partage à personne.
